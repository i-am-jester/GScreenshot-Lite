Security Architecture

  • No Mid-Server Hosting: Screenshots go directly from your local browser canvas to the Google APIs. We do not operate databases or cloud servers to store your files.
  • Minimal Permissions Scopes: We request only `drive.file` permissions. This means the extension can only view and update files that it creates itself; it cannot access your other personal documents.
  • Proprietary & Secure: Built with secure runtime libraries adhering to Chrome Extension sandbox standards to prevent cross-script vulnerabilities.
