# 🌐 GScreenshot Lite Website

[![Website](https://img.shields.io/badge/Website-Live-2fb4f6?style=flat-square)](https://i-am-jester.github.io/GScreenshot-Lite/)

This repository contains the source code for the official landing page and documentation website of the **GScreenshot Lite** Chrome Extension, hosted at [i-am-jester.github.io/GScreenshot-Lite/](https://i-am-jester.github.io/GScreenshot-Lite/).

## 🚀 Features
- **Sleek, Responsive UI**: Crafted with Bootstrap 5 and customized premium graphite styling matching the extension's look and feel.
- **Privacy & Terms Pages**: Complete, Google OAuth-compliant documentation templates for Privacy Policy and Terms of Service.
- **Robust SEO & Metadata**: Pre-configured meta tags for search engines, OpenGraph previews, and Twitter Cards sharing.

## 🛠️ Stack
- **HTML5 & CSS3 & JavaScript**
- **Bootstrap 5 (via CDN)**
- **Google Fonts (Outfit)**

## 📁 Structure
- `index.html`: Homepage with features grid and security details.
- `privacy-policy.html`: Google OAuth-compliant privacy policy page.
- `terms-and-conditions.html`: Comprehensive terms of service page.
- `css/styles.css`: Central stylesheet containing layout styling and animation rules.
- `js/main.js`: Main JavaScript file handling the preloader logic with minimum loading duration.
- `images/`: Directory containing page preview mockups and the application favicon icon.
- `.htaccess`: Folder listing prevention and local server configs.
